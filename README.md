# Credit Wise Loan Approval

This repository contains a Streamlit application for predicting loan approval using the `loan_approval_data.csv` dataset.

## Deployed App

[Credit Wise Loan Approval · Streamlit](https://tabby-rohit-credit-wise-project-streamlit-app-affd0u.streamlit.app/)

## Run locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the app:
   ```bash
   streamlit run streamlit_app.py
   ```
